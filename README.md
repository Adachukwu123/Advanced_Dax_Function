# 📊 Data Professional Survey Analysis (Power BI Project)

## 📌 Project Overview
This project presents an interactive Power BI dashboard built from a Data Professional Survey dataset. The goal is to analyze trends in salaries, job roles, programming languages, and employee satisfaction across different countries.

The project demonstrates data cleaning, transformation, and the use of advanced DAX to generate meaningful insights.

---

## 🎯 Objectives
- Analyze salary distribution across different job roles
- Identify popular programming languages among data professionals
- Evaluate work-life balance and salary satisfaction
- Understand geographic distribution of survey participants
- Assess difficulty level in breaking into the data field

---

## 🛠️ Tools & Technologies
- Power BI
- Power Query (Data Cleaning & Transformation)
- DAX (Data Analysis Expressions)

---

## 🔄 Data Preparation
The dataset was cleaned and transformed using Power Query:
- Removed null and inconsistent values
- Standardized column names
- Created calculated columns
- Structured data for analysis

---

## 📐 DAX Calculations
Advanced DAX was used to enhance analysis:
- Created calculated columns for averages
- Aggregated salary metrics by job role
- Built measures for KPIs such as:
  - Average Salary
  - Average Age
  - Satisfaction Scores

---

## 📊 Dashboard Features

###  Country Distribution
Shows the number of survey participants across countries.

###  Average Salary by Job Title
Highlights salary differences across roles such as:
- Data Scientist
- Data Engineer
- Data Analyst
- Data Architect

###  Programming Language Preference
Displays the most commonly used programming languages (e.g., Python, R, SQL).

### Work-Life Balance Satisfaction
Gauge visualization indicating overall happiness with work-life balance.

###  Salary Satisfaction
Shows how satisfied respondents are with their salary.

### Difficulty to Break into Data
Visualizes how easy or difficult respondents find entering the data field.

---

## 📈 Key Insights
- Data Scientists earn the highest average salary among surveyed roles
- Python is the most preferred programming language
- Work-life balance satisfaction is moderate
- Many respondents report difficulty entering the data field
- Salary satisfaction is lower compared to work-life balance

## 🚀 How to Use
1. Download the `.pbix` file
2. Open using Power BI Desktop
3. Interact with filters and visuals
